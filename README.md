# Smart Classroom Occupancy Counter

An Arduino Uno-based smart classroom system that uses two IR sensors to count people entering and leaving a room and automatically controls the light based on occupancy.

## Features

- Bidirectional people counting using dual IR sensors
- Real-time occupancy count on 16×2 LCD
- Automatic light control using a relay
- Supports more than two occupants
- Prevents the count from going below zero

## Hardware

- Arduino Uno
- 2 × IR sensors
- 16×2 LCD
- Relay module
- Light/LED
- Breadboard and jumper wires

## Software

- Arduino IDE
- Embedded C/C++
